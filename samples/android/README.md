# Android sample — Kotlin + OkHttp

Reference integration: [`app/src/main/java/io/mocklane/sample/integration/MocklaneBootstrap.kt`](app/src/main/java/io/mocklane/sample/integration/MocklaneBootstrap.kt).

1. Start Mocklane Desktop (**Listening :6625**).
2. Emulator: open in Android Studio or `./gradlew :app:installDebug`.
3. Physical device: **Connect Android** in Desktop, then launch the app.
4. Tap **Run all** — same scenarios as web/iOS/Flutter.

```bash
cd samples/android && ./gradlew :app:assembleDebug
```
