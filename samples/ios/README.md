# iOS sample — URLSession + SwiftUI

Reference integration: [`App/MocklaneIOSSampleApp.swift`](App/MocklaneIOSSampleApp.swift) + [`App/DemoRunner.swift`](App/DemoRunner.swift).

```bash
cd samples/ios
xcodegen generate
open MocklaneIOSSample.xcodeproj
```

On a physical device, you connect over USB and run **Connect iOS** once. For smoke automation, launch with `-MocklaneSmoke` (runs **Run all**).

See [`../README.md`](../README.md).
